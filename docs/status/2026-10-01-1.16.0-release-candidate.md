# Kinocut 1.16.0 release candidate

**Status:** prepared, not published. PyPI and npm still serve 1.15.3.
The candidate shim is `mcp-video==1.6.15`, with every extra pinning
`kinocut==1.16.0`. The candidate registers 203 MCP tools and 177 CLI commands, adding MCP audio mixing and motion receipts plus CLI mixing, ducking, motion receipts and HLS. Published 1.15.3 remains at 201/173.

## Three agent-facing release bullets

1. Agents gain Python audio mixing/ducking and source-bound temporal inspection
   with separate human motion acceptance. Optional vision inference remains an
   explicit, bounded capability; sampled evidence does not replace whole-film
   human review.
2. Media execution, cancellation, diagnostics and publication have stronger
   ownership and resource bounds. Input validation, audio timing and retained
   destination protection are repaired. Real Hyperframes integration now executes
   instead of passing with skipped-only tests.
3. Existing MCP/CLI names, canonical/legacy imports and environment compatibility
   remain supported. Upgrade the legacy installer to 1.6.15 alongside canonical
   1.16.0, preserve optional extras, and restart the actual MCP process after
   draining active work.
