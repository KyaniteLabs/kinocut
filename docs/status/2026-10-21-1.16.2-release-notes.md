# Kinocut 1.16.2 release notes

**Date:** 2026-10-21  
**Surface:** 203 MCP tools / 177 CLI commands (unchanged)  
**Compatibility shim:** `mcp-video` 1.6.17 → `kinocut` 1.16.2

## Why this release

The MCP Registry entry for `tech.kyanitelabs/kinocut` 1.16.1 listed only a hosted
URL and no installable package. Kinocut runs locally on the user's machine, so
1.16.2 republishes the entry from `server.json`: the PyPI package `kinocut`, run
with `uvx kinocut` over stdio.

## Changes

- **Registry:** local package only; a distribution test fails if `server.json`
  advertises a hosted remote or drops the package. The publish workflow signs in
  with the `kyanitelabs.tech` domain key for `tech.kyanitelabs/*` and with GitHub
  OIDC for the `io.github.KyaniteLabs/mcp-video` shim entry.
- **`create-from-images`:** frame-exact output, rational frame rates such as
  `30000/1001`, `--list FILE` / `list_file` input, bounded sequences and fatal
  decode errors (#616, contributed by @Beritwu). Frame rates above 60 are now
  rejected for Python and CLI callers, matching MCP.
- **Tests:** an intermittent process-cleanup test failure is fixed (#618).
