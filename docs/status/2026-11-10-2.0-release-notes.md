# Review the cut in chat with Kinocut 2.0.1

Your agent trims a video. Then it hands you a file path and waits. You open a player, scrub, come back and type “looks good.”

Ask for a review card in a local Hermes Desktop session and Kinocut can put the cut’s contact sheet and video details in the chat. The card shows the filename, duration, resolution, frame rate, codec and size. Choose **Approve & export**, **Dig in** or **Try another range** to send the corresponding request back to your agent. The card shows still frames from the cut.

Kinocut 2.0.1 uses FFmpeg to shrink large contact sheets, so the card works on a plain install without Pillow. Human-readable CLI output also shortens your home directory to `~`.

## What the agent can call

Kinocut 2.0.1 exposes **18 MCP tools by default**. Eight are direct calls for info, trim, merge, text, audio, frame grabs, shorts and doctor. Eight family tools route **205 operations**, including `video_review_card` via `video_edit_ops`. The remaining two tools, `list_operations` and `describe_operation`, let an agent look up an operation and load its input schema on demand.

**Migrating from 1.16.5?** Twelve names moved off the default list. Use the family tools for eleven of those operations, and use `list_operations` to discover them in default mode. Set `KINOCUT_TOOLS=all` in your MCP server environment to expose **206 direct tools**, including `search_tools` and all twelve names from the old default list that moved.

The `kino` CLI lists **177 commands** in `kino --help`. See the [Kinocut 2.0 release notes](https://github.com/KyaniteLabs/kinocut/releases/tag/v2.0.0) for the full list of changes from 1.16.5.

## Get it

With Python 3.11 or later and FFmpeg on your PATH:

```bash
pip install --upgrade kinocut==2.0.1
kino doctor
```

If you use Claude Code and have `uv` installed, add Kinocut as a local MCP server:

```bash
claude mcp add kinocut -- uvx --from kinocut==2.0.1 kino --mcp
```

Kinocut 2.0.1 is available on [PyPI](https://pypi.org/project/kinocut/2.0.1/) and [npm](https://www.npmjs.com/package/kinocut/v/2.0.1).
