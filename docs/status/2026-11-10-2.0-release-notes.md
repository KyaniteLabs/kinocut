# Kinocut 2.0: review the cut where you asked for it

Your agent trims a video. Then it hands you a file path and waits. You open a player, scrub, come back and type "looks good".

In 2.0, ask for a review card and the agent shows you the cut in the chat: a frame from the cut, its duration, resolution and codec, and three buttons. **Approve & export**, **Dig in**, **Try another range**. Click Approve and the agent runs the quality check and the release gate.

It also costs your agent less to carry. The default tool list is 18% smaller, and its 18 tools now reach all 205 operations. In 1.16.5 the default list reached 20.

**What it doesn't do yet.** The card shows a frame, not a player. The Hermes status bar names the running Kinocut tool but shows no percentage. Both are next.

**This is a breaking release:** twelve tools left the default list. Details at the end.

## Smaller tool list, everything reachable

- **An 8-tool hot path** for what you do every day: info, trim, merge, text, audio, frame grab, shorts and doctor.
- **Eight operation families** for everything else: edit, effects, audio, AI, image, QC, planning and platform.
- **`list_operations` and `describe_operation`** so the agent finds an operation and fetches its schema only when it needs it.

Help text now sits on the parameter it explains, and schema titles nobody reads are gone.

| | 1.16.5 | 2.0 |
| --- | --- | --- |
| Default tool list | 20 tools, 26.5 KB | 18 tools, 21.7 KB, reaches all 205 |
| `KINOCUT_TOOLS=all` | 225 KB | 178 KB |
| Tool description text, all tools | 62.5 KB | 31.2 KB |

Want the long list back? `KINOCUT_TOOLS=all` lists every tool by name.

## In Hermes

Turn on Capabilities > Plugins > Kinocut. The status bar then shows which Kinocut tool is running, and a Kinocut tab lists recent runs.

## Sturdier

- **Kill the CLI and FFmpeg dies with it.** No more orphaned encoders burning CPU in the background.
- **Screen recordings get their own quality profiles.** `ui-capture-dark` and `ui-capture-light` score dark-mode and light-mode recordings fairly, and the report says which profile ran. A black frame still fails.
- **Loudness you can see.** Normalize reports measured loudness before and after, and keeps its true-peak headroom.
- **`release-checkpoint` no longer reports `all_passed` when a check failed**, and design auto-fix applies every fix it reports.
- **Works on more machines.** Text overlays find a font on Arch and other distros without DejaVu. FFmpeg 9 works for upscaling and loudness checks. Hardened containers that block reading `/` can write output again.
- **The 360 flow refuses raw `.insv`** and anything that isn't a stitched equirect, before it decodes a frame, and says what to export instead.
- **One fewer heavy dependency.** The audio-analysis extra no longer installs librosa.

## Get it

```bash
pip install --upgrade kinocut==2.0.0
claude mcp add kinocut -- uvx --from kinocut==2.0.0 kino --mcp
```

Hermes users: update the Kinocut plugin.

If your agent called one of the twelve tools that left the default list, it can call the family instead, or set `KINOCUT_TOOLS=all`. The full notes, breaking changes first, are in the CHANGELOG.
