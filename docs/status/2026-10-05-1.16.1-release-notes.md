# KinoCut 1.16.1 maintenance release

This patch retains 203 MCP tools and 177 CLI commands. The compatibility installer
`mcp-video==1.6.16` pins `kinocut==1.16.1`. Publication is a separate gate: consult
the official package registries and `docs/public_claims.json` for verified delivery.

## Fixes

- Preserve original audio packets, timestamps and priming information through
  shader and upscale processing; fail closed when media probes fail.
- Bound shader frame extraction and report renderer dependency/startup failures
  through typed errors.
- Make MP4 faststart relocation bounded and preserve the original output when
  staging or validation fails.
- Publish model-cache downloads and signed C2PA outputs through owned staging.
- Handle macOS zombie-process observations without signaling unrelated processes.
- Recognize current FFmpeg capability flags and correct platform test fixtures.

## Verification

The final implementation passed 8,973 tests, with 193 skips and eight warnings.
Affected release metadata and packaging checks are run separately after the version
cut. Native audio preservation was verified with real media and controlled render
backends. These checks do not establish GPU rendering quality, optional model
acceptance, fleet rollout or MCPB Desktop acceptance.

Website artwork, directory/vendor identity merges and ChatGPT/Claude distribution
remain separate projects with their existing acceptance gates.
