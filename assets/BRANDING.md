# KinoCut primary identity

The colored logo and Chakra Petch Bold700 horizontal lockup are approved.
`kinocut-hero.webp` supplies the README hero; the repository-root
`og-social-preview.png` supplies the GitHub settings upload; `og.jpg` supplies
the canonical website social card. GitHub settings and website deployment require
separate live verification. The approved 512px logo is packaged at `mcpb/icon.png`.

`kinocut-wordmark.svg` contains original font glyph paths with native kerning,
not live font-dependent text or an embedded bitmap. Its original description
retains historical candidate wording; the subsequent owner approval governs the
unchanged source. Chakra Petch is licensed under the adjacent SIL Open Font
License, `CHAKRA-PETCH-OFL.txt`; the letterforms are unmodified.

This wordmark is distinct from the optional simplified optical icon companion.
Primary approval does not approve that historical companion or its favicons.
